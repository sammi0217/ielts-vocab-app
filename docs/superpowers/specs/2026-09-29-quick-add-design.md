# 設計：課堂生字快速新增（做法 A）

日期：2026-09-29　狀態：已實作

- 入口：篩選列表 →「＋ 新增課堂生字」→ 底部面板：單字（必填）、中文（必填）、同義詞（逗號分隔）、分類（預設「閱讀課」，記住上次）。
- 一組同義字存一列：寫進「單字庫」最後一列（A 編號續號、K 未學習、O/P 空）。同名字（不分大小寫）拒絕，回 `exists`。
- 直接呼叫 API（`sync.request`），不進離線佇列：新增需要伺服器回傳列號，離線時提示無法新增。成功後重新 `load` 取得正式資料。
- 新增的字不進 7 份輪替；可在篩選列表依分類翻卡，拼字分頁會依分類列出「課堂單字」練習組。
- Apps Script 新 op：`{op:"add", w, zh, syn?, cat?, pos?, note?}` → `{ok, row}`；錯誤 `exists` / `bad_request`。
